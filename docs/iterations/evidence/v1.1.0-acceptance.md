## Visual Acceptance

The Electron renderer was inspected through its development debugging interface. Each state was accepted only when both conditions were true:

1. the local endpoint returned the expected state;
2. the renderer DOM exposed the expected visible GIF and state class at the same moment as the screenshot.

Observed results:

| State | Renderer evidence | User-visible behavior |
|---|---|---|
| `idle` | base pet visible; no state class | normal pet |
| `thinking` | `think-img: block`; class `thinking` | question-mark thinking animation |
| `working` | `work-img: block`; class `working` | keyboard work animation |
| `attention` | `attention-img: block`; class `attention` | question-mark pulse; intentionally reuses thinking art |
| `happy` | `happy-img: block`; class `happy` | sparkle completion animation |
| `sleeping` | `sleep-img: block`; class `sleeping` | eyes-closed sleep animation |

The first operating-system window screenshots looked like Idle even after HTTP `200`. Investigation showed that transparent-window capture and short 3–5 second animations made those screenshots unreliable. The gate was therefore not lowered: inspection moved closer to the renderer and paired DOM evidence with a same-moment image.

## Fixture-Driven End-to-End Check

The seven official-shape fixtures were sent through the real Python process while Electron was listening on `127.0.0.1:18920`.

```text
session-start.json:          125.98 ms
user-prompt-submit.json:      37.41 ms
pre-tool-use.json:            37.23 ms
post-tool-use.json:           35.00 ms
permission-request.json:      35.51 ms
stop.json:                    37.66 ms
session-end.json:             45.06 ms
median:                       37.41 ms
maximum:                     125.98 ms
```

Every invocation exited `0`, wrote exactly `{}` to stdout, and left stderr empty. A same-call renderer inspection additionally confirmed:

- `stop.json` → `happy-img: block` and class `happy`;
- `session-end.json` → `sleep-img: block` and class `sleeping`.

These measurements cover Python process startup through local HTTP response and IPC delivery. They do not claim a scientifically measured photon-to-eye latency; the visual state was verified separately.

## Packaging Evidence

The standard arm64 build produced:

```text
dist/mac-arm64/WorkBuddy Pet.app
CFBundleShortVersionString: 1.1.0
Executable: Mach-O 64-bit arm64
```

The original 160×160 runtime pixel asset did not satisfy the builder's 512×512 icon requirement. A separate 512×512 transparent package icon was added while preserving the runtime sprite.

An early DMG helper download timed out against the GitHub CDN. A local fallback artifact was created at that point:

```text
dist/WorkBuddy Pet-1.1.0-arm64-local.dmg
Format: compressed read-only UDIF (UDZO)
Compressed bytes in use: 115,821,840
```

The local DMG proves that the arm64 application can be packaged into a mountable read-only image. It does not prove that the configured `electron-builder` DMG job passed.

After restoring the build runtime's npm executable path and retrying when the external download recovered, the standard command completed and produced:

```text
dist/WorkBuddy Pet-1.1.0-arm64.dmg
Size: 101 MB
Format: compressed read-only UDIF
SHA-256: f23d1394b3b6a97a41745d74e0a7af085a8bce73cbf3698881dd629a1cbe48be
```

The successful standard artifact supersedes the local fallback for release testing. The timeout and fallback remain recorded because they demonstrate the difference between an external build interruption and a product-code failure.

The packaged `.app` executable was then launched directly. It bound `127.0.0.1:18920`, accepted `stop.json` through the Python Hook with neutral `{}` output, accepted a manual `working` state with HTTP `200`, and remained alive. The Mac was locked during this final runtime smoke, so no packaged-window screenshot was claimed; the six-state visual evidence was collected separately from the development build.

5. Review the 17 high-severity findings reported in the inherited Electron build dependency tree; do not use a blind forced upgrade.
